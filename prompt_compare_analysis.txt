请分析以下句子中词汇的替换可能性：

## 句子
{sentence}

## 候选词
{words}

## 输出格式要求
Return the answer as a JSON object.

## 示例
```json
{
    "answer": "fission",
    "translation": "核裂变是一个释放巨大能量的过程。",
    "analysis": [
        {
            "word": "fission",
            "is_correct": true,
            "explanation": "名词，指分裂、裂变（核裂变、细胞分裂），与句子语境（nuclear, energy）完美匹配"
        },
        {
            "word": "fissure",
            "is_correct": false,
            "explanation": "名词，指裂缝、裂隙，与 nuclear 搭配不自然，不能描述能量释放过程"
        }
    ]
}
```

## 注意
- answer 是填入空格的正确单词，必须从候选词中选择，且只能有一个
- answer 应选语境下最地道、最贴切的词；即使其他词语法上可行，也不能作为 answer
- 候选词不分主次，请独立判断哪个最适合空格，不要预设某个词更可能是答案
- is_correct 一律只对 answer 为 true；其余词一律为 false，但 explanation 必须如实区分三种情况：
  - 与 answer 可行度接近、难以区分优劣的词：如实说明「与 XX 可行度接近，均可使用」，
    不要为了凑出唯一答案而强行贬低它；此时以语域（正式/口语/文学）、典型搭配、
    语义侧重与句子的匹配度作为决胜标准，而不是以词频或常见度决胜——
    较少见的词只要语域和搭配与句子更吻合，就应该成为 answer
    （否则近义词组中较少见的词永远选不上，其例句会全部作废）
  - 语法可行但不如 answer 贴切的词：说明可行但欠贴切的原因，以及与 answer 的语义/搭配差别
  - 完全不适合该语境的词：说明为什么不能使用，以及它的真实含义是什么
- 对 answer 本身，explanation 要说明为什么它最适合这个语境
- translation 是句子的中文翻译
- Do not write any commentary outside the JSON.
